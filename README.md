# ICARIA SAE Numeration verification script

Python script to check and detect potential errors on Serious Adverse Events (SAEs) in the ICARIA Clinical Trial, specifically on SAE numeration and possible ghost entry errors (errors in data entry caused by complex tablet-server issues).

This script was intended to be run periodically to detect and correct errors on SAEs numerations and to prevent errors regarding ghost entries in SAEs.
